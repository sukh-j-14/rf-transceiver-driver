02 / UNDER THE HOODNATIVE C ARCHITECTURE
01

Inject the bus

The driver receives read and write callbacks. The mock supplies an in-memory register bank, keeping the C API independent of its transport.

radio_init(&r, bus, polls)
02

Bound every wait

Initialization waits for READY; sending waits for DONE. Each operation stops after its status-read budget. These are poll counts, not milliseconds.

RF_OK · RF_IO · RF_TIMEOUT
03

Recover explicitly

A failed send may leave partial data or an in-progress operation. Clear the fault, reinitialize, retune, and send again. Calls must be serialized.

initialize → tune → send
